# 🏋️ FITNESS & GYM — CRM для фитнес-клуба

B2B SaaS-помощник для управления фитнес-клубом в формате **Telegram Mini App**.

Клиенты, абонементы, депозиты, бар и аналитика выручки — всё внутри Telegram, без установки отдельных приложений.

---

## 📱 Что умеет

### 👥 Посетители
- Живой поиск по имени и телефону
- Цветовая индикация статуса (просрочен / истекает / активен)
- Продление абонемента на любое число дней с кастомной суммой
- Депозиты клиентов: пополнение и списание
- Полная история операций по каждому клиенту
- Удаление клиента со всей историей

### 🍷 Бар и склад
- Учёт товаров с ценой, себестоимостью и остатком
- Продажа с выбором количества одной кнопкой
- Быстрое пополнение склада (+1, +5, +10, +50, +100)
- Предупреждение при низком остатке
- Редактирование цен и удаление позиций

### 📊 Аналитика
- Выручка за день, неделю, месяц, произвольный период
- Календарь для выбора точных дат
- График динамики выручки
- Разбивка: абонементы vs бар
- Лента последних операций

### 🤖 Telegram-бот
- Команда `/start` с приветствием и кнопкой запуска
- Menu Button в интерфейсе Telegram
- Открытие Mini App прямо в чате

## 🛠 Стек

**Backend:**
- Node.js (>= 22.5)
- Express — REST API
- Telegraf — Telegram Bot
- Встроенный `node:sqlite` — база данных без внешних зависимостей

**Frontend:**
- Vanilla JS + HTML + CSS
- Без фреймворков и сборки
- Дизайн: тёмная и светлая темы, glassmorphism

**Безопасность:**
- HMAC-SHA256 валидация Telegram `initData`
- Whitelist админов по Telegram ID
- Rate limiting (300 запросов/мин глобально, 60/мин на чувствительные)
- Helmet — защита HTTP-заголовков
- Параметризованные SQL-запросы (защита от инъекций)
- Транзакции для денежных операций
- Скрытие внутренних ошибок от клиента

## 🚀 Запуск

### 1. Установка зависимостей
```bash
npm install
2. Настройка окружения
Скопировать .env.example в .env и заполнить переменные:

env
BOT_TOKEN=<токен бота из BotFather>
WEBAPP_URL=<публичный HTTPS-адрес приложения>
ADMIN_TELEGRAM_IDS=<telegram-id администратора>
PORT=3000
DEV_MODE=false
NODE_ENV=development
3. Запуск
bash
npm run dev
Сервер запустится на http://localhost:3000.

⚠️ Для работы в Telegram Mini App требуется HTTPS-адрес (туннель или хостинг).

🔌 API
Все эндпоинты (кроме /api/health) требуют заголовок X-Telegram-Init-Data.

🔐 Безопасность
Валидация Telegram initData
Каждый запрос к API проверяется по HMAC-SHA256:

Подпись формируется из данных, отсортированных по ключам

Используется timingSafeEqual (защита от timing-атак)

Проверка свежести — данные старше 24ч отклоняются

Только админы из whitelist получают доступ

Защита данных
Все SQL-запросы параметризованы

Денежные операции — в транзакциях (атомарность)

Rate limiting на глобальном и чувствительных эндпоинтах

Helmet — HTTP-заголовки безопасности

🎨 Дизайн
Тёмная тема: мятно-зелёный акцент на тёмном фоне с glassmorphism

Светлая тема: кремово-зелёная палитра

Переключение темы сохраняется в localStorage

Полностью адаптивно под мобильные устройства
